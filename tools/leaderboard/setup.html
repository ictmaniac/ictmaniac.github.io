লিডারবোর্ড চালু করা (৫ মিনিট)

💻 এটা কম্পিউটারে করুন (ফোনে কঠিন)। যে গুগল অ্যাকাউন্টে করবেন, ছাত্রদের নম্বর সেই অ্যাকাউন্টের গুগল শিটে জমা হবে। একবার করলে আর কখনো কিছু করতে হবে না।

  1. নতুন গুগল শিট খুলুন।
    এই লিংকে যান: sheets.new
    উপরে বাঁয়ে নাম দিন: ICT Maniac Leaderboard
  2. স্ক্রিপ্ট খুলুন।
    উপরের মেনু থেকে Extensions (এক্সটেনশন) → Apps Script চাপুন। নতুন একটা ট্যাব খুলবে।
  3. কোড কপি করুন।
    এই বোতাম চাপুন:
    ✓ কপি হয়েছে!
  4. পেস্ট করে সেভ করুন।
    Apps Script ট্যাবে বড় সাদা ঘরে যা লেখা আছে সব মুছে দিন (Ctrl + A, তারপর Delete)। তারপর পেস্ট করুন (Ctrl + V)। উপরে 💾 Save চাপুন।
  5. চালু করুন।
    উপরে ডানে নীল Deploy → New deployment।
    "Select type" এর পাশে ⚙️ চাপুন → Web app।
    Execute as = Me
    Who has access = Anyone
    তারপর Deploy চাপুন।
  6. অনুমতি দিন।
    Authorize access → আপনার অ্যাকাউন্ট বেছে নিন।
    "Google hasn't verified this app" লেখা এলে নিচে ছোট করে লেখা Advanced → Go to … (unsafe) → Allow।
    ভয়ের কিছু নেই: স্ক্রিপ্টটা আপনার নিজের, তাই গুগল যাচাই করেনি। এটা শুধু আপনার এই শিটে নম্বর লেখে।
  7. লিংকটা আমাকে পাঠান।
    শেষে Web app এর নিচে একটা লিংক আসবে (শেষে /exec লেখা)। Copy চেপে চ্যাটে Claude কে পাঠিয়ে দিন। বাকি সব আমি করব।

পরে কি কিছু করতে হবে?

না। ছাত্ররা টেস্ট দিলে নম্বর নিজে থেকে শিটে জমা হবে, লিডারবোর্ডও নিজে বদলাবে। নতুন টেস্ট যোগ করলেও শিটে কিছু করতে হবে না।

শুধু চাইলে: কেউ খারাপ নাম দিলে শিটে নিচে + চেপে blocked নামে একটা পাতা বানিয়ে A কলামে তার মোবাইল নম্বর লিখে দিন। সে লিডারবোর্ড থেকে সরে যাবে।
