# আলাদা পরীক্ষা (ফ্রি পরীক্ষা, নতুন সিরিজ)

প্রতিটা নতুন পরীক্ষার ধরনের জন্য এখানে একটা আলাদা ফোল্ডার, যেমন `src/exams/free/`।
প্রতিটা ফোল্ডারের নিজের লিডারবোর্ড থাকে ("সব টেস্ট মিলিয়ে" শুধু ওই ফোল্ডারের টেস্টগুলো যোগ করে)।

- `_series.json`: `{"title": "ফ্রি পরীক্ষা", "hub": "<৮ অক্ষরের কোড>"}` (hub = এই সিরিজের সব টেস্টের তালিকা পেজ)
- `<কোড>.json`: একটা টেস্ট, বইয়ের টেস্টের মতো একই ধরন (`src/tests/` দেখুন), চাইলে `"order": 1`।

তারপর `python3 tools/build_tests.py`। গুগল শিটে কিছু বদলাতে হয় না: স্ক্রিপ্ট `a/lb-tests.json` থেকে নতুন টেস্ট নিজে চিনে নেয়।
বইয়ের ৩০টা টেস্ট আছে `src/tests/` এ (সিরিজের নাম `book`)।
