যেসব সূত্র বেশি লাগে

A + A' = 1A · A' = 0
A + 1 = 1A · 0 = 0
A + A = AA · A = A
A + AB = AA(A + B) = A
A + A'B = A + B(A + B)(A + C) = A + BC
(A + B)' = A'B'(AB)' = A' + B'

কৌশল: আগে সাধারণ অংশ বাইরে আনো (কমন নাও), তারপর A + A' = 1 বা 1 + X = 1 খোঁজো।
