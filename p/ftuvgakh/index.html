IMICT Maniac অধ্যায় ৩ · ৩.১.৬–৩.১.১১ কোড: BCD, ASCII, EBCDIC, ইউনিকোড

কম্পিউটার অক্ষর চেনে কীভাবে?

প্রতিটি অঙ্ক বা অক্ষরের জন্য একটি নির্দিষ্ট বিট-নকশা আছে, তাকেই কোড বলে। কিছু লিখে দেখো কোডে কী হয়।

BCD (Binary Coded Decimal)

দশমিক সংখ্যার প্রতিটি অঙ্ককে আলাদা করে ৪ বিটে লেখা হয়। একে 8421 কোডও বলে।

BCD

সরাসরি বাইনারি

  • ৪ বিটে 16টি নকশা হয়, কিন্তু BCD তে শুধু 0000–1001 (0–9) ব্যবহার হয়। 1010 থেকে 1111 এই ৬টি অবৈধ।
  • BCD সহজে পড়া যায়, তবে সরাসরি বাইনারির চেয়ে বেশি বিট লাগে।

ASCII

American Standard Code for Information Interchange। ৭ বিটের কোড, তাই 27 = 128টি অক্ষর। সামনে একটি 0 বা প্যারিটি বিট যোগ করে ৮ বিটের ASCII-8 বানানো হয়।

  • A = 65, B = 66 … Z = 90; a = 97 … z = 122; 0 = 48 … 9 = 57; স্পেস = 32।
  • বড় হাতের আর ছোট হাতের অক্ষরে পার্থক্য ঠিক 32 (একটি বিট)।

EBCDIC

Extended Binary Coded Decimal Interchange Code। IBM এর তৈরি ৮ বিটের কোড, তাই 28 = 256টি অক্ষর। প্রথম ৪ বিট জোন, শেষ ৪ বিট ডিজিট।

ইউনিকোড

পৃথিবীর সব ভাষার অক্ষরের জন্য একটি কোড। মূল রূপটি ১৬ বিটের, তাই 216 = 65,536টি অক্ষর রাখা যায়। বাংলা অক্ষরের ঘর U+0980 থেকে U+09FF।

  • ইংরেজি অক্ষরের ইউনিকোড মান ASCII এর মতোই (A = U+0041 = 65)।
  • একটি বাংলা "যুক্তাক্ষর" আসলে কয়েকটি অক্ষর মিলে তৈরি, তাই একাধিক কোড দেখাবে।
